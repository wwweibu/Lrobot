基础

帮助​

  • 群聊:公测、内测和内阁判断为"管理"
  • 私聊:内阁判断为"管理"
  • 使用 re 分割内容
  • 如果长度为 2:
    • 基础功能返回对应说明
    • 管理功能同时判断管理身份
    • 均未匹配返回"未知"
  • 长度不为 2
    • 返回基础功能
    • 若管理，同时返回管理功能

常见问题​

  • 使用 re 分割内容
  • 如果长度为 2:
    • 如果为数字
      • 返回对应问题回答
  • 返回常见问题列表

欢迎​

  • 添加时发送
  • 其中 LR232,WECHAT 为私聊添加发送类型（另外两种识别到发送则为发送类型）

活动​

  • 获取当前活动

修改活动​

  • 使用 re 分割
  • 第二段为活动

书单​

  • 获取书单
  • 如果为 WECHAT 和 BILI（字数限制）
    • 发送图片

修改书单​

  • 使用 re 分割指令和书单
  • 同时保存书单图片到 command/book.png

留言​

  • 发送至管理员 qq

网址​

  • temp_key 每十分钟变化一次
  • 返回包含 temp_key 的网址

转发​

  • 对于'/'开头的消息，识别为指令，此时返回“无效的指令”
  • 对于非 LR5921 的消息，转发给管理员
