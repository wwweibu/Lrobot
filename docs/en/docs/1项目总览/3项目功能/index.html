项目功能

  • 此处仅提供功能快照
  • 具体功能介绍可以参考:
  • 不配置任何参数，docker compose up --build -d lrobot
  • 访问http://localhost:5922/cmd，输入 lrobot，lrobot
  • 等待跳转后，点击功能页查看功能

指令功能​

基础说明​

\<使用方式>
私聊:直接发送指令
群聊:@机器人并发送
\<指令列表>
输入'/帮助,基础'等获取详细指令
指令包括基础、入会、收集表、游戏、工具、订阅、活动、系统几类
指令说明中,[]是需要替换的
第一项为平台,全代表四个平台,LR代表两个QQ,232代表LR232,5921代表LR5921,W代表微信,B代表B站
存在'私'则私聊可用；存在'群'则群聊可用
下方为管理指令,分别是平台、私聊、群聊的可用范围
\<其他>
任何指令中英文逗号均通用
LR232可输入'/'或点击机器人图标唤出指令面板
\<平台>
LR232:QQ,群管理下方添加
LR5921:QQ,群管理中添加(3502644244)
BILI:B站,武大推协
WECHAT:微信公众号,武大推协
网站: https://whumystery.cn/home

基础​

⌈全⌋⌈私⌋⌈群⌋ /常见问题: 获取常见问题列表
⌈全⌋⌈私⌋⌈群⌋ /常见问题,[序号]: 获取对应问题回答
⌈全⌋⌈私⌋⌈群⌋ /活动: 获取当前活动
⌈全⌋⌈私⌋⌈群⌋ /书单: 获取推荐书单
⌈全⌋⌈私⌋ /留言[内容]: 进行留言
⌈全⌋⌈私⌋ [转发消息]: 转发除 LR5921 外其他平台所有未匹配消息至微步
⌈全⌋⌈私⌋ [转发消息]: 对于未匹配的以'/'开头的私聊消息，返回"无效的指令，请使用'/帮助'"

⌈全⌋⌈全⌋ [私聊添加]: 欢迎消息
⌈LR⌋⌈微部⌋⌈内阁⌋ /修改活动,[内容]: 修改当前活动
⌈LR⌋⌈微部⌋⌈公测,内阁⌋ /修改书单,[内容]: 修改推荐书单
⌈5921,B,W⌋⌈内阁⌋⌈内阁⌋ /网址: 获取管理页临时网址

入会​

⌈全⌋⌈私⌋ /入会: 第一步，获取入会说明
⌈全⌋⌈私⌋ [入会信息]: 第二步，编辑并发送信息
⌈全⌋⌈私⌋ [图片]: 第三步，发送付款截图，成功入会

⌈5921⌋⌈微部⌋ [入会信息]: 通过小推编辑信息入会

收集表​

⌈全⌋⌈私⌋ /收集表: 获取当前正在进行的收集表
⌈全⌋⌈私⌋ /收集表,[序号]: 开始填写对应的收集表
⌈全⌋⌈私⌋ [回答内容]: 选择收集表填写后，收集回答内容，发送下一个问题

⌈LR⌋⌈内阁⌋⌈公测,内阁⌋ /收集表设置,名称,[时间],[问题]: 设置收集表
⌈LR⌋⌈内阁⌋⌈公测,内阁⌋ /收集表结果: 获取完整收集表列表
⌈LR⌋⌈内阁⌋⌈公测,内阁⌋ /收集表结果,[序号]: 获取对应收集表结果
⌈LR⌋⌈内阁⌋⌈公测,内阁⌋ /收集表删除,[序号]:删除指定序号的收集表

⌈5921⌋⌈公测⌋ [群聊添加]: 触发更新成员列表

社团网站​

主页​

  • 答题活动，并展示社团信息
  • 可拖动地图，点击卡片解谜
  • 上方输入框输入答案触发菜单、输入经纬度跳转位置、输入其他查找并转到第一个结果
  • 移动端下可左右拖动（需按住顶部或按住卡片）

错误页​

  • 404 页，访问未知路径时展示

登录页​

  • 登录页，管理员与测试员的登录处，管理员使用限时验证码，测试员使用账号密码
  • 登录无论输入什么都会显示未知的指令
  • 但管理员会收到验证码，测试员直接输入密码即可
  • 登录完成自动跳转

管理页​

  • 管理员首页，包含 6 个页面的跳转，以及网页操作、指令操作的成功数，指令的时间数、平台数、用户数，词云

功能页​

  • 测试页/功能页，管理员和测试员可访问，包含当前指令功能、界面功能，以及待办

以下页面仅管理员登录后才可访问

上边栏​

  • 包含 wiki，功能，网盘，时间轴，指令，数据库，日志，用户页面按钮
  • 右上角为当前页面功能说明（跳转到本页）
  • 移动端变成右侧灰色按钮，点击展开

wiki页​

  • wiki页，协会的wiki
  • 分为一级和二级标题，可展开、收起一级标题
  • 一级标题也可点击查看内容（若存在）
  • 左侧为导航栏，右侧为展示的 markdown 内容
  • 右上角可编辑当前页面内容，左下角可新建页面，设置标题和分组
  • 双击左侧一级和二级标题可编辑
  • 拖动一级标题、二级标题（前面的小方框）可排序
  • 编辑区域可在右侧预览，右上角保存
  • 若需上传图片，使用对应的 wiki 命令'/wiki'获取图片链接
  • markdwon 书写教程在左侧菜单最下面
  • BUG:C-A拖入A组时不触发合并组，需要刷新才能成功
  • BUG:若存在很多数据或者相同数据，拖入后有几率错误

网盘页​

  • 网盘，可自由进行上传文件/文件夹、下载、重命名、移动、创建目录、删除等操作，并可预览大多数类型文件，支持视频文件的流式预览
  • 预览
    • 点击文件预览
    • 目前已测试：asp,avi,bmp,cfm,css,csv,dat(概率),data(概率),doc,docx,epub,f4v,gif,html,ico,inc,ini,jpeg,jpg,js,log,lst,m4a,m4v,md,mkv,mov,mp3,mp4,obj,ogg,pdf,png,ppt,pptm,pptx,psd,py,raw,rtf,sh,svg,tiff,ts（文件，非视频）,txt（utf8\gbk）,wav,webm,webp,wmv（转换很慢）,wps,xls,xlsx（合并单元格会转换回去）,xml,yaml,yml
    • 不支持 7z,apk,bak,bz2,chm,db,dll,dwg,exe,fbx,fmu,gz,heic,idml,indd,lit,mdb,otf,pdg,pyc,rar,tar,ttf,wpsonline,xz,zip
    • pdf 电脑点击按钮缩放，手机双指缩放
    • epub 电脑点击/使用左右键翻页，手机使用按钮翻页
  • 搜索
    • （bug）如果搜索后为空，可以点击空位右键上传新文件，上传的文件会出现在左上角的路径出现
  • 路径
    • 上方显示当前路径，可点击跳转对应路径
  • 排序
    • 可选择名称、修改时间、大小的正序倒序
    • 不支持文件夹大小排序
  • 拖拽
    • 电脑端可拖拽文件进文件夹
  • 右键菜单
  • 除夸克外均可正常触发
  • 夸克会触发默认的智能助手，会出现下载图片等菜单，点一下空白处消失，此时网盘右键菜单仍存在
  • 下载
    • 可下载文件及文件夹
    • 下载文件夹时会生成压缩包
    • 速度 10MB/20s 左右
  • 重命名
    • 可重命名，记得设置正确的后缀
  • 移动到
    • 移动到 xx/xx，如果移动到根目录请使用移动到根目录
  • 移动到根目录
  • 删除
  • 上传文件
  • 上传文件夹
    • 限制 2GB

时间轴页​

  • 时间轴，展示协会一年的活动时间轴，可自由添加、修改、移动时间节点，支持多类型事件
  • 电脑端滚轮缩放，手机端双指缩放，右上角是缩放大小，点击重置可重置缩放进度
  • 电脑端单击/移动到节点后显示详情，手机端单击显示详情
  • 双击节点编辑，双击空白/点击添加添加新节点
  • 按住拖动移动时间轴

指令页​

  • 指令，配置指令，编辑名称、响应内容、匹配方式、消息类型、适用平台、触发状态、适用用户和群聊、触发函数、分组

开发者操作

  • 新建指令
  • 保存指令
  • 修改指令
    • 选项中，平台在前端配置，状态、类型、用户、群组在后端配置
    • 顺序填写 1，2，3 正序，-1，-2，-3 倒序
    • 手机端有点丑
  • 删除指令
  • 移动指令
  • 分组展开/收起

数据库页​

  • 数据库，以腾讯文档多人协作的方式编辑后端数据库，可新建/删除行、修改数据

开发者操作

  • 选择对应表格查看数据
  • 点击编辑
  • 左侧删除，下方添加新行

日志页​

  • 日志，支持时间、来源、级别、事件的筛选以及消息内容的检索与正则检索，自动分页100/页，按钮可一键输入属性

开发者操作

  • 添加条件查询日志，左侧为整段词语匹配，右侧为正则表达式（右侧可以用'^数字/字母'作为前缀搜索比左侧更快）
  • 使用按钮查询日志

用户页​

  • 用户组，配置后端管理员和适配群的用户组

开发者操作

  • 新增、编辑、删除用户组和用户
