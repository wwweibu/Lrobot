网页测试

主页​

  • 左右切换图片
  • 点击翻面（检测的位置有些奇怪，偏左偏右
  • 翻面的在切换时不会自动翻回
  • 翻面时会将之前翻的翻回
  • 下方链接可跳转
  • 手机端
    • 卡片显示最开始偏右，之后逐渐偏左
    • 无论点击何处都只能翻过当前卡片
    • 二维码截图能正常扫描

线索板页​

  • 左上角显示表情
  • 答题逻辑可选择正确答案或D
  • 移动逻辑正常
  • 搜索逻辑正常
  • 音乐正常
  • 答案正常
  • 缩小屏幕宽高后地图大小不变，出现黑边
  • 缩小屏幕宽度后地图旋转90度
    • 且移动逻辑错位

由于只写了一个逻辑，故电脑尽量不要缩小宽度，或者缩小宽度的同时缩小高度

  • 手机端
    • 左上角显示备用线路（无网络环境）
    • 移动逻辑正常
    • 音乐、答案正常

愚人节活动页​

  • 活动页 1
  • 提示框可正常点击、拖动
  • 娃娃点击后会落到页面底部而不是页面真实大小底部（特性）
  • 缩小屏幕
  • 手机端
    • 拖不动（特性）
  • 活动页 2
  • 缩小后输入框会到下面
  • 重新放大后不会回来（刷新即可）
  • 手机端
    • 输入框自动在下面

登录页​

  • 电脑及手机均显示正常

管理页​

  • 六个按钮跳转正常
  • 监控数据显示正常
  • 缩小屏幕后出现滚动条正常（两栏变一栏）
  • 手机端
    • 显示及跳转正常
    • 就是有点容易划过头

wiki 页​

  • 左侧目录正常点击
  • 左侧一级、二级标题正常移动、重命名
  • 左侧二级标题重命名后自动合并
  • 手动去数据库页删除
  • 修改保存正常

功能页​

  • 添加删除后刷新，正常

网盘页​

  • 上传文件 160MB/60s
    • 手机 153MB/79s
  • 上传文件夹
  • 新建文件夹
    • 阻止非法路径序列
    • 阻止重复文件名
    • 手机夸克会提示:联系方式(手机/qq/邮箱)（？？？）
  • 下载文件 160MB/353s
    • 非流式下载 160MB/390s（可能整体打包传输变慢了？）
    • 手机 153MB/335s
    • 下载不存在的文件会显示不存在
  • 重命名（重名、空名）
    • 阻止非法路径序列
    • 阻止重复文件名
  • 移动到
    • 阻止非法路径
    • '/' 代表根路径
  • 移动到根目录
  • 拖动
  • 跳转到目录
  • 删除文件夹
  • 搜索
    • 然后跳转到目录
  • 点左上地址栏跳转
  • 预览
    • 5s 后，不可预览的文件会显示不可预览
    • 视频类
      • 手机夸克会出现"当前页面出现错误"，但可以正常播
