/常见问题，3

Q: 活动的频率以及参与方式（怎么报名，是否必须参与）

A: 所有活动包括协会组织的与自发组织的，均为自愿参与，无强制报名
大型活动每年1次，平均每月1-2场
日常活动每周1-2场（加上自发组织的则天天有）
活动均在会员群内通知，每年招新时至校园寻宝前，活动会在招新群内通知
