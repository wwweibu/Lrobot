指令测试-帮助

/帮助​

  • 可区分普通用户和管理员，可返回管理员临时地址
  • 微信以图片形式发送
  • LR232 返回白名单内的管理员地址，非临时地址
  • 群内 @LR232 时不会触发 LR5921
  • 可以检测 @ 中包含的空格
  • 使用群内的机器人指令与私聊的均可正常触发
  • 由于是包含匹配且未做其他检测，'/帮助xxxxxx'的消息也会发送帮助内容
  • 普通用户字段
<指令>
输入'/帮助,基础'(入会、收集表、游戏、工具、订阅、活动、系统)获取指令组详细指令
你将看到:'/常见问题,[序号]: 获取对应问题回答 (全)(私)(群)'类似的回答
前面是用法,[]需要替换,例如,'/常见问题,1'
后面的为解释,指令的功能
第一个括号是平台,全代表四个平台,LR代表两个QQ,232代表LR232,5921代表LR5921,W代表微信,B代表B站
括号存在'私'则私聊可用；存在'群'则群聊可用
<平台>

LR5921:QQ,群管理中添加(3502644244)
BILI:B站,武大推协
WECHAT:微信公众号,武大推协
网站: https://whumystery.cn/home
<其他>
任何指令中英文逗号均通用
LR232可输入'/'或点击机器人图标唤出指令面板
LR232在群聊中使用需要先@
